# 稳定版与 1.0 就绪评审 {#stable-release-and-1-0-readiness}

`0.1.0-rc.3` 已发布。下一项决策是：文档中非实验性功能的范围是否已达到发布 **0.1.0** 的条件，而不是要求完成路线图上的全部功能。下方的 1.0 评审是独立的兼容性决策，不会自动升级版本。未关闭的 issue 数量少，并不等于通过验收。

## 已交付内容 {#what-has-been-delivered}

原始路线图的基础工作与提案（#43、#46–#63）、可选编写约定（#88–#92）、路由数据与 Suspense（#118–#119）、标签页样式与可见性（#122–#123），以及 rc.3 导航体验（#117、#133–#138）均已完成各自 issue 定义的范围。研究 issue 的关闭表示调查已有结论，不表示已交付通用的生产 API。

[功能概览](./capabilities)解释各平台组件的职责。[兼容性指南](./compatibility#api-scope)定义冻结的 API，并列出仍属实验性的功能。例如，Android 预测返回转场原型的 issue 已关闭，但对应的上游 Core 实现并未因此发布。

过去通过验收的候选版，只能证明当时的修订版本，不会免除对新发布 commit 的验证。缺少的硬件覆盖仍为**未验证**，直到完成测试，或维护者明确接受这一已记录的限制。iOS 测试版真机结果可补充、但不能替代受支持的模拟器基线。仅凭使用时长或下载次数，无法证明已达到发布条件。

## 后续工作与研究结论 {#follow-ups-and-investigation-decisions}

- **#139：** 已定位 Core 原因，[NativeScript #11587](https://github.com/NativeScript/NativeScript/pull/11587)提出修复，[PR #160](https://github.com/rafaelaugustos/vue-router-ns/pull/160)记录原生验证。已发布的 Core 9.1.3 仍受影响。应等待修复发布、更新依赖并重新执行消费应用/原生测试矩阵，或在发布决策前明确缩小支持的组合范围。
- **#152：** [已发布版本的消费应用报告](https://github.com/rafaelaugustos/vue-router-ns/blob/main/test/native-rc3-consumer.md)分别记录真机 VoiceOver 服务输出、模拟器 TalkBack 步骤与结果，以及 UI 断言。目前没有 Android 真机；维护者已接受模拟器验证及其限制。请先阅读语音与手势的验证边界，不要将其视为全面的无障碍认证。
- **#145：** [v1 观察接口提案](https://github.com/rafaelaugustos/vue-router-ns/blob/main/research/transition-observation/README.md)记录原生生命周期证据及保持适配器私有的决定。缺少权威条目 ID，且不支持并发修改目标，因此尚不能提供公开控制器。连续 UIKit 转场进度和 Jolt 适配器不属于稳定版的必要条件。
- **#64：** 路线图用于索引已交付范围与当前后续工作，不应在无明确决策的情况下把实验性集成升级为稳定功能。

如果修复改变行为或冻结的 API，可继续发布候选版。当以上条件均有证据、维护者接受剩余的已知限制后，通过发布工作流发布 0.1.0。后续的 1.0.0 决策还需要独立的 API 兼容性承诺与应用实践，不能仅由 issue 列表清空得出。

### 提议的 1.x 兼容性承诺 {#proposed-1-x-compatibility-commitment}

- 公开导入包括 `package.json#exports` 中声明的入口、其文档化的值/类型，以及 Vue 组件契约。文件出现在 `src/` 或 `dist/` 中，不代表支持对这些文件进行深层导入。
- 稳定兼容性不仅包括函数名称，也包括选项默认值、导航失败与结果、守卫执行顺序、条目所有权与生命周期，以及受支持的平台行为。
- “实验性”表示支持范围和验证证据较窄。在 1.0 之前，需要决定将该 API 纳入 1.x 承诺，还是迁移到一个具有显式版本的可选契约。不能仅因指南标注“实验性”，就在次版本中破坏已有根导出的兼容性。
- 稳定契约的不兼容变更需要主版本升级及迁移指南。新增功能与兼容修复可通过次版本或补丁版本交付。本次评审没有删除 API，也没有将实验性 API 升级为稳定 API。
- 不必仅为完成路线图而增加抽屉模式、实时 DevTools 控制器、Jolt 适配器或预测返回原型。新的应用需求可以成为单独开展这些工作的理由。

[评审证据](https://github.com/rafaelaugustos/vue-router-ns/blob/main/test/release-readiness.md)记录源码修订、检查结果与限制。本次评审不授权发布，也不声称每个导出的 API 都完成了新的硬件测试。
