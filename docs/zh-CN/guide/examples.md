# 观看。建造它。 {#watch-it-build-it}

选择完整的应用程序或集中的原生交互。每张卡都会打开一个指南，其中包含录制内容、可运行源和平台限制。从 [您的第一个应用程序](./first-app) 开始，然后按照 [Fieldnotes](./native-showcase) 来编写更多功能。

过滤器描述 **平台记录的**，但并非该功能支持的每个平台。原生剪辑来自实际的模拟器/仿真器版本。诊断查看器在浏览器中运行，并带有明确的综合教学报告。

## 查找特定任务 {#find-a-specific-task}

使用[常见任务](./recipes)进行身份验证、未保存的编辑、独立选项卡、深层链接和状态恢复。 [功能食谱](./demo)保留现有视频和可复制片段，包括按版本标识的旧录音。

对于连接到您设备的浏览器编辑器，请尝试 [StackBlitz Playground](./playground)。有关支持的包/运行时基准，请参阅 [compatibility](./compatibility)。
