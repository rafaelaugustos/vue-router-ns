# Míralo. Constrúyelo. {#watch-it-build-it}

Elige una aplicación completa o una interacción nativa enfocada. Cada tarjeta abre una guía con los límites de grabación, fuente ejecutable y plataforma. Comience con [, su primera aplicación](./first-app), luego siga las notas de campo [Notas de campo: un ejemplo de navegación nativa integrada](./native-showcase) para crear más funciones.

Los filtros describen **, la plataforma registrada**, no todas las plataformas compatibles con esa función. Los clips nativos provienen de compilaciones reales de simuladores/emuladores. El visor de diagnóstico se ejecuta en un navegador con informes de enseñanza explícitamente sintéticos.

## Encuentra una tarea específica {#find-a-specific-task}

Utilice [tareas comunes](./recipes) para autenticación, ediciones no guardadas, pestañas independientes, enlaces profundos y restauración de estado. El libro de recetas de características [Ejemplos y videos por característica](./demo) conserva los videos existentes y los fragmentos copiables, incluidas las grabaciones más antiguas identificadas por versión.

Para obtener un editor de navegador conectado a su dispositivo, pruebe [StackBlitz Playground](./playground). Para conocer la línea base de tiempo de ejecución/paquete admitido, consulte [compatibilidad](./compatibility).
