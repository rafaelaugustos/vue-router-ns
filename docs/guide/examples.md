# Watch it. Build it.

Choose a complete app or a focused native interaction. Each card opens a guide with the recording, runnable source and platform limits. Start with [your first app](./first-app), then follow [Fieldnotes](./native-showcase) to compose more features.

Filters describe **the platform recorded**, not every platform supported by that feature. Native clips come from actual simulator/emulator builds. The diagnostics viewer runs in a browser with explicitly synthetic teaching reports.
