# Veja funcionando. Construa o seu.

Escolha um app completo ou uma interação nativa específica. Cada card abre um guia com vídeo, código executável e limites por plataforma. Comece pelo [primeiro app](./first-app) e siga para o [Fieldnotes](./native-showcase) para combinar mais recursos.

Os filtros indicam **a plataforma gravada**, não todas as plataformas suportadas pelo recurso. Os vídeos nativos vêm de builds reais em simuladores/emuladores. O visualizador de diagnósticos executa no navegador com relatórios didáticos explicitamente sintéticos.
