# Packed NativeHost consumer

This disposable iOS app installs router and adapter tarballs. It has no source
aliases into the repository. Its first command runs the public conformance
harness against the independent adapter, starting with an unloaded Frame.

The remaining commands expose real native Back cancellation, guard blocking and
commit; temporary unloading/reloading through a retained owner Page; navigation
after reappearance; and final owner disposal with pending result settlement.
A UIKit recognizer observer proves the successful and cancelled swipes actually
started; the blocked swipe must produce no recognizer progress. The observer is
fixture-only and does not replace the platform gesture/navigation delegates.

Use the [driver instructions](../../scripts/native/native-host/README.md). Generated
native resources and platforms are ignored. The fixture is not a production app.
