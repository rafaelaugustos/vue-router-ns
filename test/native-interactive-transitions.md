# Interactive transition investigation — #136

Validated 2026-10-24 against published Core 9.1.3 / NativeScript-Vue 3.1.2, iOS runtime 9.1.0 and Android runtime 9.1.1. No runtime router implementation or installed dependency was patched. The dedicated devices were an iPhone simulator on iOS 26.0 and `RouterPredictive62API36` on Android 16/API 36.

## Native evidence

| Scenario                  | iOS Frame/UIKit                                                                                                                        | Android Frame/default preview                                                                                                     |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Reversing native gesture  | Native coordinator reports cancellation; both histories retain detail; result pending; Page not disposed                               | Actual system gesture cancel; real progress received; no page navigation                                                          |

| Navigation during gesture | Replace requested while sampled coordinator was interactive; after reversal histories agree and no diagnostic issue/result duplication | Existing default-preview gesture coverage plus replace/clear-history; Core candidate interruption belongs to earlier #62 evidence |

| Modal inner Back          | Covered by existing native contract suite, not re-executed here                                                                        | Inner pop preserves presenter; modal result remains pending until actual modal dismissal, then settles once                       |

XCTest's native input runner passed its complete scenario sequence (64 seconds). Fifteen Android runner reports passed. iOS cancelled-gesture samples reached approximately 0.318 for ordinary Back and 0.531 for zoom; those are observations from these gestures, not an API guarantee. Guard-held zoom had no interactive samples. UIKit coordinator completion distinguishes cancelled versus committed interaction. A 25 ms **fixture-only** observer records progress and completion without replacing delegates or simulating callbacks.

The video in the PR and guide records the actual iOS fixture. XCTest screenshots, `Documents/transitions.json` (all command captures) and Android intermediate/post-gesture screenshots are generated by the [reproduction scripts](../scripts/native/transitions/README.md). The checked-in summary below retains scenario outcomes without bundling device logs.

Root unit suite: 640 passed, 10 skipped. Demo type check, library build and EN/pt-BR documentation build passed. No extra emulator matrix was added to the pull-request gate.

## Decision and follow-up

Keep the existing APIs for rc.3. The [EN](../docs/guide/interactive-transitions.md) / [pt-BR](../docs/pt-BR/guide/interactive-transitions.md) guide contains the owner/platform matrix, guard ordering, cleanup and fallback requirements, and an optional observer/presentation-session proposal. [#145](https://github.com/rafaelaugustos/vue-router-ns/issues/145) tracks the host capability follow-up, outside the rc.3 gate. Optional Jolt integration waits for that contract; no dependency is added.

[NativeScript #11558](https://github.com/NativeScript/NativeScript/pull/11558) remains open/unmerged as checked on this date, at candidate `fadb58f034e403933028f86746280375ea9811ff`. Its Frame-owned bitmap session and recreation fix have their own earlier evidence in `native-predictive-back.md`. They are not properties of published Core 9.1.3.

## Limits

No claim of physical-device performance, arbitrary shared-transition cancellation, UIKit split/multiwindow gesture parity or a cross-platform continuous progress API. NativeScript's bridge names are `interactive` and `cancelled` (not Objective-C getter spellings); the probe uses the published typings. Await native presentation rather than assuming a fixed duration for UIKit zoom.

Reduce Motion behavior is source-audited through `src/motion.ts`, router admission and preview cleanup; this run does not claim a new OS-toggle or spoken screen-reader matrix. Native buttons remain available. VoiceOver/TalkBack speech/focus, device motion comfort, accessibility interruption and background/multiwindow interruptions remain manual or separate-host acceptance. The timed replacement test covers one observed native gesture interruption, not every lifecycle interruption.
